# 추가 가중치 검증의 AWS Spot 견적

산정일: 2026-10-12. **사용자가 $15 한도 GPU 확대 실행을 승인했고 EC2 Spot 작업이 완료됐다.** 기존 CPU 시범에 든 AWS 비용은 $0이다. GPU 계산 구간은 318.65초였고, 시작부터 첫 종료 상태 관측까지 포함한 인스턴스 비용의 보수적 추산은 약 $1.23이다. 부대비용·세금은 별도이며 확정 청구액은 아니다. [실행 결과와 종료 확인](11-spot-weight-provenance-analysis.md)을 참조한다. 아래 금액은 실행 전 견적 기록이다.

실행 후보는 오하이오 `use2-az2`의 `g6e.12xlarge`이다. EC2 반환값의 `InstanceLifecycle=spot`을 확인했다. On-Demand 자동 전환은 없다. 최대 Spot 단가는 $6.50/시간, 인스턴스 종료 감시는 110분으로 설정했다.

## 승인 요청 범위: 추론 없는 가중치 검사 확대

- Solar Open 2↔Solar Open 1, K-EXAONE 2.0↔K-EXAONE 선행 모델을 우선 확대 검사한다.
- 공통 토큰 embedding 정렬에 쓰는 행 수를 확대하고, 호환되는 GQA attention 층의 UCKA와 스펙트럼을 더 수집한다.
- 알려진 변환에 대한 양성 대조와 독립 음성 대조를 포함한다. 실제 독립 모델의 호환 구조와 고정 리비전 확보를 실행 조건으로 삼는다.
- A.X K2는 embedding 정렬 검사까지 포함한다. MLA/SGA 및 FP8 attention 복원은 별도 구현 검증이 필요하며 이 견적이 그 완료를 보장하지 않는다.
- GPU 계산만 한다. 전체 250B~750B 모델을 추론용으로 로드하지 않는다. MoE forward를 실행하지 않으므로 기존 추론 환경의 Hopper 제약을 이 수치 계산 작업에 그대로 적용하지 않는다.
- REEF, LLMPrint, 전체 LLM-DNA 추론 및 모델 재학습은 이 견적에 포함하지 않는다. 필요하면 별도 견적과 승인을 받는다.

## 후보 인프라와 현시점 가격

사용자 지정 [Spot 대시보드](https://d16jdvzof4zpo7.cloudfront.net/)의 `data.json` 생성 시각은 2026-10-12 10:11 UTC였다. API 읽기 조회로 인스턴스 사양, 가격, AZ ID와 quota를 교차확인했다.

| 항목 | 후보 |
|---|---|
| 서비스 | EC2 Spot 단일 인스턴스 |
| 리전 | `us-east-2` (오하이오) |
| AZ ID / 이번 계정 AZ 이름 | `use2-az2` / `us-east-2b` |
| 인스턴스 | `g6e.12xlarge` |
| GPU / RAM | L40S 4개, GPU 메모리 약 179GiB 합계 / CPU RAM 384GiB |
| 대시보드 AZ Spot 점수 | 9 / 10 |
| 조회한 현재 Linux/UNIX Spot 가격 | **$5.2599 / instance-hour** |
| 조회한 EC2 G/VT Spot quota | 128 vCPU; 후보는 48 vCPU. 실제 가용 잔여 quota는 실행 직전에 재확인 |

AZ 이름은 계정에 따라 달라질 수 있으므로 AZ ID를 기준으로 한다. 대시보드 및 AWS의 높은 점수도 할당·무중단을 보장하지 않는다. 실행 직전에 점수와 가격을 다시 확인한다. EC2 Spot 가격을 SageMaker Managed Spot 청구액으로 취급하지 않는다.

## 비용 계산

| 항목 | 산정 가정 | 예상 USD |
|---|---|---:|
| GPU 인스턴스 | 1~2 instance-hours × $5.2599 | $5.26~$10.52 |
| EBS·공인 IPv4·소규모 로그/결과 저장 | 최대 200GiB root/cache, 짧은 보관 및 소규모 결과. 지역별 단가는 실행 전 확인 | 예비비 $0.50 |
| 중단·재시도 및 가격 변동 여유 | 전체 승인 한도 안에서만 사용 | 남은 한도 |
| **승인 요청 총한도** | **USD, 세금 제외** | **$15** |

계산 시간은 소규모 CPU 시범과 행렬 크기를 바탕으로 한 계획값이다. 대형 모델의 전체 구현 벤치마크에서 측정한 확정 시간은 아니다. 동일 리전에서 직접 내려받고, 대용량 결과를 리전 밖으로 전송하지 않는다. NAT Gateway는 만들지 않는다. 전체 모델 저장 비용과 학습 비용을 이 소규모 작업에 포함한 것으로 이해하면 안 된다.

## 한도 관리 및 종료 조건

- 사용자 승인 전 인스턴스·EBS·버킷·역할 등 AWS 자원을 새로 생성하지 않는다.
- 허용 Spot 단가 상한은 $6.50/시간. 상한 밖이면 시작하지 않고 재견적한다.
- 재시도를 포함한 총 인스턴스 실행 시간은 최대 2시간. 부팅·다운로드·계산 시간을 모두 포함한다.
- 부족한 데이터·호환 실패가 있으면 더 큰 인스턴스로 자동 전환하지 않는다. 같은 결정적 실패를 반복하지 않는다.
- 작업 종료 또는 시간 제한 도달 시 인스턴스를 terminate하고 임시 볼륨을 삭제한다. 결과와 자원 종료 상태를 확인한다.
- $15는 이 작업의 운영 예산이다. AWS 전체 계정의 다른 비용을 제한하거나 청구를 기술적으로 보장하는 AWS Budgets 한도는 아니다. 세금과 이미 존재하는 다른 자원 비용은 제외한다.

## 견적을 검증한 읽기 조회

- `ec2 describe-instance-types`: GPU/RAM/instance store 사양.
- `ec2 describe-spot-price-history`: AZ별 Linux/UNIX 가격.
- `ec2 describe-availability-zones`: 계정의 AZ 이름과 ID 매핑.
- `ec2 get-spot-placement-scores`: `use2-az1/2/3`에서 모두 9.
- `service-quotas get-service-quota`, `L-3819A6DF`: EC2 G/VT Spot quota.

실행할 실제 부모 후보와 음성 대조군, 산출물 경로, 소프트웨어 버전은 승인 후 실행 전에 고정한다. 준비 중 비교 구조가 맞지 않으면 이 견적으로 관련 없는 대체 모델의 결과를 대신 내지 않는다.
