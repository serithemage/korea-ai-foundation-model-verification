“From Scratch”를 확인하려면, 모델이 얼마나 잘 답하는지보다 어떤 가중치로 학습을 시작했는지를 살펴봐야 합니다.

현재 확인한 핵심

Solar Open 2와 K-EXAONE 2.0은 자체 선행 모델의 가중치를 이어받았습니다. A.X K2는 처음부터 학습했다고 밝혔고, 검사한 표본도 그 주장과 부합합니다. 다만 세 모델 모두 전체 학습 이력을 독립적으로 확인한 것은 아닙니다.

이 페이지는 공개본의 예비검증입니다. 실제 평가 제출본과의 동일성은 미확인입니다. 정부의 평가 결과나 사업 적격성을 판정하는 보고서가 아닙니다.

먼저, 두 질문을
구분합니다.

“새 모델”과 “처음부터 학습한 모델”은 같은 뜻이 아닙니다.

이번 세대가 처음부터 출발했나?

이 보고서는 학습 가중치를 모두 무작위 값으로 초기화한 경우를 세대별 From Scratch로 봅니다. 이미 학습된 가중치를 조금이라도 옮겼다면 이 정의에는 해당하지 않습니다.

자체 기술의 계통을 이어갔나?

개발사가 직접 만든 선행 모델을 확장할 수도 있습니다. 자체 모델의 계승을 외국 모델 차용으로 해석해서는 안 됩니다. 선행 모델 자체의 기원은 별도로 확인해야 합니다.

토크나이저는 문장을 작은 조각으로 나누는 도구입니다. 세 모델 모두 이전 세대의 전체 BPE 병합 순서가 일치했습니다.

같은 토크나이저로 새 가중치를 학습할 수 있습니다. 따라서 토크나이저의 재사용만으로 가중치까지 재사용했다고 판단하지 않습니다.

같은 위치의 가중치 2,048개씩을 시작·중간·끝에서 읽었습니다. 전체 모델의 극히 작은 일부입니다.

비교한 표본의 원본 byte가 완전히 같은 경우는 없었습니다. 추가 학습으로 이전 가중치도 바뀔 수 있어, 해시가 달라도 계승을 배제할 수 없습니다.

아직 확인하지 못한 것

  • 평가 제출본과 공개본의 동일성. 정확히 같은 체크포인트인지 연결할 자료가 필요합니다.
  • 무작위 초기화부터의 전체 학습 이력. 초기 체크포인트, seed, 학습 코드와 중간 기록이 필요합니다.
  • 전체 가중치의 기원. 일부 표본으로 모든 가중치나 모든 외부 후보를 검사하지는 못합니다.
  • 새 방법에 의한 교차검증. 아래 문헌 조사와 실제 대상 모델의 실행 결과는 구분합니다.

따라서 지금의 결론은 공개 자료와 표본이 어디까지 뒷받침하는가에 대한 판단입니다. “검사에서 찾지 못함”은 “존재하지 않음의 증명”과 다릅니다.

다음에는 어떻게 확인할까

Exa로 조사한 연구 방법입니다. 이 목록 자체가 세 모델에 적용한 결과는 아닙니다.

가중치의 순서가 달라도 비교

AWM은 좌표를 정렬한 뒤 가중치를 비교합니다. GhostSpec은 attention 가중치의 스펙트럼과 층의 대응을 살핍니다. 단순 cosine이 놓칠 수 있는 변형을 다루는 후보입니다.

답변과 내부 표현을 함께 비교

REEF는 같은 입력에 대한 내부 표현을 비교합니다. LLMPrint는 특화된 질문으로 모델의 token 선호를 드러냅니다. 독립 모델 대조군과 오탐 통제가 필요합니다.

학습 시작부터의 기록을 검증

Proof-of-Learning과 Proof-of-Training-Data는 개발사의 학습 기록을 검사하는 접근입니다. 초기 상태와 학습 경로를 함께 확인해야 합니다.
